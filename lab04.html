Unit Testing Lab – Google Test (GTest)

1. Introduction / Description

Unit Testing is a method where individual units or components of software are tested in isolation to ensure correctness. Google Test (GTest) is a powerful testing framework for C++.

In this lab, you will create a simple Calculator program and write unit tests using GTest.

2. Required Equipment / Software

  • C++ compiler / IDE
  • Google Test (GTest) library installed

3. Procedure

Step 1: Write Code to Test

Create calculator.h and calculator.cpp.

// calculator.h
class Calculator {
public:
    int add(int a, int b);
    int subtract(int a, int b);
    int multiply(int a, int b);
    double divide(double a, double b);
};

Step 2: Set Up Test Environment

#include <gtest/gtest.h>
#include "calculator.h"

Step 3: Write Test Cases

// test.cpp
TEST(AdditionTest, PositiveNumbers) {
    Calculator calc;
    EXPECT_EQ(calc.add(2, 3), 5);
    ASSERT_EQ(calc.add(10, 20), 30);
}

TEST(AdditionTest, NegativeNumbers) {
    Calculator calc;
    EXPECT_EQ(calc.add(-2, -3), -5);
}

TEST(AdditionTest, WithZero) {
    Calculator calc;
    EXPECT_EQ(calc.add(5, 0), 5);
}

Step 4: Compile & Run

Compile calculator.cpp, test.cpp, and GTest together, then run the executable.

Step 5: Analyze Results

You will see pass/fail results in the console. Fix any issues until all tests pass.

Step 6: Report

Document your code and include screenshots of GTest output showing successful tests.
